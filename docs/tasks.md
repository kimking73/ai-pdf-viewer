## 다음 세션 시작점 (2026-11-06 기준)

**위치:** 사용자가 설치한 앱에서 아이콘, `설정` 버튼, 쪽 이미지 질문, 수식, 재실행 후 키 유지, 구분선·글자 선택·작은 영역 드래그를 확인했다(2026-11-06). 모델은 임시값 `gpt-6-luna`를 유지한다.

**마지막 창 검사(2026-11-05~06, 1회):** E2E 30개 전부 통과, `test:packaged` 전부 통과(패널의 `설정`으로 키 입력 창이 열림 포함). 300쪽 첫 쪽 81ms, 이미지 문서 299ms. 앱 안의 아이콘 파일이 `build/icon.icns`와 일치한다.

**남은 일:** 없다. 아래는 사용자 결정으로 하지 않는다(2026-11-06).
- 독립 코드 리뷰. 코드 검토는 구현한 세션이 직접 한 것뿐이다.
- POSTECH AI 수정. 설정 창의 POSTECH AI 항목과 호출 코드는 그대로 있고, 실제 호출은 아직 동작하지 않는다(아래 미룬 항목).
- 품질 배너 앱 확인. 단위 테스트만 통과했고 앱에서는 확인하지 않았다.

**창이 뜨는 검사 규칙(사용자와 약속):** E2E와 패키징 앱 확인은 앱 창을 실제로 띄워 사용자 작업을 가린다. 사용자가 요청할 때만 1회 실행하고, 실패하면 재실행 없이 결과부터 보고한다. 이전 세션에서 에이전트가 같은 테스트를 약 100회 넘게 반복해 사용자가 중단시켰다.

## 미룬 항목
- POSTECH AI(사용자 지시로 나중에 수정, 2026-11-05): 입구 인증은 통과하지만 형식과 무관하게 HTTP 200으로 `<div cls="error" attr="10000"></div>`를 돌려준다. 가짜 키는 HTTP 401 `Gateway authentication failed`다. 코드 뜻, 쓸 수 있는 에이전트, 입력 내용의 저장·학습 규칙을 학교에 확인해야 한다. 고칠 것: 인증을 통과하면 키를 저장, 스트리밍(`data: {"message", "is_sse_finished"}`) 적용, `files`의 이미지 전달 확인.
- E2E 간헐 실패(원인 미확정, 다시 나오면 조사): 텍스트 드래그가 중간에 끊김(`Fixture page 1 m`), 작은 영역 드래그 뒤 칩이 남음(`e2e/tutor.e2e.ts:205`). 코드를 고치지 않았는데 최근 통과했으므로 해결로 보지 않는다. 구분선 드래그는 창 수준 입력으로 고친 뒤 실패하지 않았다.
- `e2e/viewer.e2e.ts:35`, `e2e/tutor.e2e.ts:28`에 테스트 전용 `setIgnoreMouseEvents(true)`가 남아 있다. 앱 코드에는 영향이 없다.
- 알려진 사소한 문제: 내용이 손상된 PDF가 최근 문서 목록에 남는다. 여러 줄 `\[ \]` 수식 안에서 `- `로 시작하는 줄을 목록으로 읽을 수 있다. `\pmb`, `\sideset`은 배포 CSP에 막혀 스타일이 적용되지 않는다.
- 계약 [제안] 항목 중 미룬 것: 패널 폭·접힘 저장, `F6` 포커스 순환, 깨진 텍스트 칩 경고와 [영역으로 바꾸기](문서 진단 필요), 15초 안내. 60초 무응답은 제공사 오류로 처리한다.
