## 4. 일정 병목과 W1 말 범위 재검토

### 근거의 한계

**소요 시간의 근거는 PRD 9절의 공수표뿐이다.** 이 표는 사람 기준이고 "엔지니어 검증을 받지 않은 추정"이며, 에이전트의 실제 소요는 미확인이다. 그래서 이 문서는 작업별 소요 시간을 적지 않는다. 공수표는 W2 말 재조정에서 실측으로 바꾼다.

| 공수표가 말하는 것 | 값 |
|---|---|
| 합계 | 24.5인일 |
| W1~W3 가용량(1인, 주 5일) | 15인일 |
| 사람 속도일 때 부족분 | 9.5인일 |

### 공수표를 읽을 때 주의할 점

표에서 직접 확인되는 사실이다.

1. **축소 순서로는 부족분을 메우지 못한다.** 공수표에서 인일을 확인할 수 있는 축소 대상은 이해도 확인(F11) 2.5인일뿐이다. 이를 줄여도 사람 속도 기준 7.0인일이 부족하다.
2. **세션 저장(F12)과 스캔본(F13)은 공수표에 항목이 없다.** 줄여서 얻는 시간을 알 수 없고, 합계 24.5인일이 이들을 포함하는지도 확인되지 않는다.
3. **표에 항목이 없는 작업이 더 있다.** 근거 표시(F5), 되짚기(F6), 전송 범위(F7), 프로토타입, 디자인 계약, 사용자 시나리오 설계가 별도 항목으로 없다. 부족분은 9.5인일보다 클 수 있다.
4. **스캔본을 빼도 영역 질문 경로는 남는다.** F3의 "텍스트 층이 없는 부분도 사각형 영역을 선택해 질문"은 절대 유지 대상이다. 절감 폭이 작을 수 있다(추정).

### 병목

| 병목 | 근거 | 감지 방법 |
|---|---|---|
| 사용자 검토 시간 | PRD는 코드 작성보다 이쪽이 병목일 가능성을 가정한다. 게이트 승인, 평가 답변 판정, 학생 모집, 테스트 진행이 모두 같은 1명에게 몰린다. 질문 약 40개에 비교 방식 수와 모델 수를 곱한 만큼 판정해야 한다 | 승인 대기 시간(PRD 14절). 사용자의 주당 가용 시간은 미확인 |
| 학생 섭외 | W1 5명, W3 온보딩 관찰 1명 이상, W4 원격 30명이 필요하다 | W1 말 섭외 인원, 비CS 포함 여부 |

### W1 말 판단 기준

PRD는 축소를 "W1 말부터 검토"하고 "W2 말 재조정 때 적용"한다고 적었다. 이 표는 W1 말 검토에 쓰며(W1-8), 적용 여부는 사용자가 정한다.
